# PostgreSQL

PostgreSQL is the primary database used by Project Ascend.

## Connection Pooling

Connection pooling allows the application to reuse database connections instead of creating a new connection for every request.

## Transactions

Transactions allow multiple database operations to succeed or fail as a single unit.

# Docker

Docker packages the application and its dependencies into containers.

## Docker Compose

Docker Compose manages multiple containers and their configuration.

# RAG

RAG allows the application to retrieve relevant information from external documents.

## Embeddings

Embeddings represent text as numerical vectors that can be compared for similarity.

## Retrieval

Retrieval finds the document chunks that are most relevant to a user's question.
